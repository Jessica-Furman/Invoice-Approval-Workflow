**Button** — the primary action element; use for calls-to-action and form submits, with exactly one green `primary` per view.

```jsx
<Button variant="primary" iconRight={<Icon name="arrow-up-right" size={18} />}>Get started</Button>
<Button variant="outline">Learn more</Button>
```

Pill-shaped. Variants: `primary` (green / near-black text), `secondary` (near-black / off-white), `outline`, `ghost`. Sizes `sm | md | lg`. Props: `fullWidth`, `disabled`, `iconLeft`, `iconRight`.
