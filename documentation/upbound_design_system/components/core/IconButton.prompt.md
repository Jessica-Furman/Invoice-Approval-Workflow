**IconButton** — a compact button holding a single icon; use for toolbar actions, close buttons, and icon-only controls. Always pass `aria-label`.

```jsx
<IconButton name="arrow-up-right" aria-label="Open" variant="primary" round />
<IconButton name="x" aria-label="Close" variant="ghost" />
```

Variants match `Button`. Sizes `sm | md | lg`. `round` makes it circular.
